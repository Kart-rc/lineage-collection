## Normative source

These decks **present the component PRDs (L01–L16)**. They are not the normative architecture.

The single authoritative production AWS view is
[`docs/architecture/lineage-platform-target.md`](../architecture/lineage-platform-target.md), whose
Mermaid block is normative and whose offline rendering is generated by
`scripts/render_target_architecture.py`. Where the two disagree, the target doc wins.

Evidence levels are normative in [`docs/prototype-coverage.md`](../prototype-coverage.md):
`LOCAL_PASS`, `SYNTH_PASS`, `LOCAL_REAL_REPOSITORY_PASS`, `AWS_REQUIRED`, `NOT_CONFIGURED`.
