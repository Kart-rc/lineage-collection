Step 01 / 09

Pin the source, not the branch.

A collection starts from an exact 40- or 64-character commit. Acquisition verifies origin, HEAD, object identities, tracked scope, bounds, and a clean checkout without executing Maven, Gradle, hooks, tests, or repository code.

boundary artifact repository-checkout/1.0.0 · exact revision + scope digest
verified
SCA collection

Exact source → durable command → coverage plan → isolated deterministic analysis → immutable evidence → consolidation → review → fenced publication. Coverage completion, not runtime availability, is the gate.

Runtime corroboration

Signed non-production lease → OTel, OpenLineage, or SDK metadata → Kinesis → runtime-validation Lambda → immutable evidence → non-blocking corroboration. No values or raw queries are retained.

API and UI

React from CloudFront/S3 → API Gateway → product-api Lambda → DynamoDB/Neptune. The local collection form submits and polls successfully; production AWS submit currently fails closed as NOT_CONFIGURED.

Deployment

Clean Git revision → tests/build → wheel, web bundle, two OCI images and digest manifests → ECR → ordered CDK deployment → Lambda canaries/Fargate task → smoke → separately authorized cleanup.

02 / release material

What actually gets deployed.

The deployment is content-addressed. Source revision, dependency lock, OCI image digest, archive digest, handler inventory, and stack outputs stay correlated.

A01 / browser

A02 / package

Python wheel

A03 / linux-amd64

A07 / workflows

A08 / infrastructure

CDK assembly + outputs

CloudFormation templates, assets, target aliases, task ARNs, queue URLs, API URL, web URL, repositories, and durable-store identifiers.

SNS ≠ work queue

SQS carries interactive, events, and batch/bulk lineage work. Kinesis carries ordered runtime observation metadata. SNS is an approved external paging topic imported by ARN; CloudWatch Lambda, Fargate, lane-age, and DLQ alarms publish notifications to it.

03 / deployable inventory

Ten handlers. One heavy worker. Managed truth.

The shared Python package is not one production service. CDK creates explicit targets with independent handler commands, IAM roles, sizing, reserved concurrency, versions, aliases, alarms, and canary groups.

04 / honest edges

The plan is visible where the wiring stops.

These are not cosmetic caveats. They separate executable behavior from infrastructure shape and approved production evidence.

NOT_CONFIGURED

AWS collection submission

POST /api/collections fails closed in the AWS product projection. The missing acquisition/enqueue stage must return a durable QUEUED resource instead of performing local-shaped synchronous work.

AWS_REQUIRED

Live operational proof

No approved-account evidence yet proves IAM/KMS behavior, workflow execution, canaries, scale, runtime production hard-deny, recovery, or fully owned cleanup.

planned

Enterprise integrations

Cognito/enterprise OIDC, AppConfig kill switches, CloudTrail evidence wiring, EventBridge schedules, Jenkins, OpenSearch, and deferred Spark/Dask analyzer packs are not configured.

partial

Runtime production boundary

Validation, profiles, leases, revocation, closed schemas, emitters, and local kill-switch behavior exist. Production must remain hard-denied until independent IAM/AppConfig controls and probes are deployed.

partial

Deployment cleanup audit

The guarded cleanup script validates account and namespace, but its current primary-stack loop does not enumerate the web stack. Treat “no unowned resources” as unproven until corrected and observed.

reconciled

Lambda count

infra/lib/runtime-assets.ts defines ten targets. The base README sentence said nine; this change reconciles the text to the implementation inventory.
