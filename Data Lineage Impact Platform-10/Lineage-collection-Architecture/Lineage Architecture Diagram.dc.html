THREE INDEPENDENT ENGINES
L04SCA engine pipeline
CHECKOUT→DETECT/ROUTE→PARSE→AST-WALK→CONFIG-RESOLVE→RESOLVE(URN)→EMIT
Parsers: sqlglot dialect matrix · dbt manifest · OpenAPI/proto.
Rule packs (tree-sitter): Python · Java/Kotlin · JS/TS · Go.
residue reasons: dynamic-name · reflection · unparseable-type → LLM handoff
same (digest, ruleset, config) → byte-identical evidence · per-run read-only creds, workspace destroyed
L05LLM gateway pipeline
TIER→CHUNK ≤8k→CONTEXT→CACHE→CALL→GUARDRAILS→EMIT | REJECT
Tiers: T1 residue · T2 no-grammar files · T3 verification (bulk lane only). PR-path requests rejected by design.
guardrail order: schema → citation exists → URN resolves → budget · first fail → persisted reject
cache key (chunk digest, promptVersion, modelId) · hit ≥ 90% gate · staged invalidation, never fleet-wide
L06Runtime plane sessions
GRANT→READY→OBSERVING→DRAIN→CLOSED(COMPLETE | INCOMPLETE)
4 emitters: OTel extractor (Ph1) · SDK lineage.emit() · Spark OpenLineage · Dask plugin (Ph2).
validator order: signature/TTL → env ≠ prod → resolver → metadata shape (closed schema)
prod deny ×2 (IAM + validator) · Kinesis partition = dataset URN → Firehose → S3 · names, never values

L07Merge & confidence rules
edgeKey = hash(from[], to, type) · provenance append-only, idempotent by provenanceId
LLM-only → LOWEST 1 mech → SINGLE +LLM → MEDIUM SCA+RT → HIGH 3 of 3 → HIGHEST
PROPOSED→PUBLISHED→STALE→TOMBSTONED+ CONFLICTING from any state

L10Fenced publication protocol
MANIFEST→RESERVE+FENCE→STAGE→VERIFY→SWAP|DISCARDED
One DynamoDB transaction advances the pointer iff reservation + monotonic token + expected-prior all match.
STAGING→ACTIVE→PRIOR→EXPIRED
rollback = pointer event, never a rewrite · single writer · rebuild from manifests, divergence = 0
